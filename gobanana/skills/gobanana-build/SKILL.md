# GoBanana build

Plugin 0.6.0. Use GoBanana tools under any prefix; with none, ask the user to connect the GoBanana connector at claude.ai or run `/mcp`. Call ping once; if its minPlugin is above 0.6.0, tell the user in one line to update (claude.ai: re-sync the org plugin; Claude Code: `/plugin update gobanana`).

These hold even if get_playbook fails:

1. Show each reference's source link, every time.
2. Never download, save or re-host reference images.
3. Never delete a canvas without the user's explicit yes.
4. Relay quota and plan messages once, as they are. Never retry in a loop.
5. Run the intake stop (read `design/gobanana/CONTEXT.md`, ask only what is missing) before `bend_brief`.
6. The hero's look, every state reachable, one language, WCAG 2.2 AA; never show an unchecked draft.
7. Place the build on the board (add_to_canvas type "build" with gb-measure's measure) when you can screenshot. End with the canvas web link.

Call get_playbook with name `gobanana-build` and plugin `0.6.0`, and follow it exactly; batch the playbooks it names in `more`.
